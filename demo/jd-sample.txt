岗位：后端研发工程师（医疗信息化方向）
公司：云岐健康科技（虚构公司，仅用于演示）
工作地点：北京 · 海淀区｜经验 3-8 年｜本科及以上

【职位描述】
1. 负责医院信息集成平台的后端研发，打通 HIS、LIS、PACS、电子病历与预约挂号系统之间的数据链路；
2. 负责门诊预约、检查预约的排班与号源管理，处理高并发抢号、超卖、退号重排等场景；
3. 负责检验检查结果互认与报告回传：对接区域平台，保证报告状态最终一致、可追溯；
4. 参与数据治理：患者主索引（EMPI）去重合并、术语字典映射、质控规则引擎；
5. 与临床、信息科、集成商共同推进接口标准化（HL7 v2、FHIR），输出接口文档与联调方案；
6. 参与线上问题排查与运维值班，保障 7×24 可用性。

【任职要求】
1. 扎实的 Java 基础，熟悉 Spring Boot、MyBatis，理解 JVM 与常见性能问题定位手段；
2. 熟悉 MySQL 索引与事务，能设计分库分表或读写分离方案；
3. 熟悉 Redis、消息队列（Kafka / RocketMQ）在幂等、削峰、最终一致中的用法；
4. 有分布式系统经验：状态机、幂等键、补偿与对账、幂等消费与重复投递处理；
5. 了解医疗行业数据特点（患者隐私、数据分级、审计留痕）者优先；
6. 有 HIS/LIS/集成平台或区域健康平台经验者优先。

【加分项】
- 熟悉 HL7 / FHIR / DICOM 等医疗数据标准；
- 有过号源、排班、预约类业务的强一致与超卖治理经验；
- 有接口治理、限流降级、灰度与回滚的工程实践。
