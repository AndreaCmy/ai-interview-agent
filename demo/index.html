复盘报告 · 复习优先级

1. Q1 — ReAct 循环
这是 AI Agent 方向的核心基础题，得分仅 3.1 说明基本功不牢；缺失的显式推理、终止条件与常见坑都是高频追问点，且该题改进话术可直接复用于多轮追问，复习投入产出比最高。
ReAct 循环可以按以下几点来讲。第一，循环步骤：每轮完成三件事 —— Thought（模型据当前上下文做显式推理，明确下一步要做什么）、Action（若需要，返回 tool_calls 指定工具与参数）、Observation（执行工具，把结果以 role=tool 回喂 messages）；如此循环直到得到最终答案。

第二，终止条件：① 模型不再发 tool_calls，直接返回最终答案，属正常终止；② 达到 max_iter 或 token / 时间预算，属兜底终止；③ 检测到重复或振荡，即同一工具、同一参数被反复调用，应中止或降级；④ 超时或上游异常，应中断并返回可读错误。

第三，常见问题：① 工具结果过大撑爆上下文，需截断、摘要或分页；② 并行调用管理，多个 tool_calls 的顺序、依赖与结果合并；③ 幻觉参数，模型编造不存在的工具或参数，需 schema 校验并在失败后回喂错误；④ 循环振荡与死循环，靠 max_iter、重复检测、超时三重兜底；⑤ 工具异常要包成 error 文本回喂，让模型有机会自纠。

第四，举例：查天气时先 Thought 判断需要天气工具，Action 调 weather(city)，Observation 返回结果后模型不再调工具，直接输出最终回答。
整场总评：Q1 回答整体方向正确，能讲清 ReAct 的基本消息流转与兜底思路，但内容偏于简化：缺少显式推理（Thought / Action / Observation）环节，终止条件不完整，常见问题仅一笔带过。作为 AI Agent 方向的基础题，该题深度明显不足，建议优先复习。
