## 逐题复盘

### Q1・ReAct 循环（3.10）

**题目**：请讲讲 ReAct 循环的步骤、终止条件与常见坑。

**你的回答**：每轮把 messages 发给模型；模型若返回 tool\_calls 就执行工具、以 role=tool 回喂；直到模型不再调工具返回最终答案。用 max\_iter 兜底，工具异常包成 error 文本回喂，避免死循环。

**改进话术（可背诵）**：

ReAct 循环可以按以下几点来讲。第一，循环步骤：每轮完成三件事：Thought（模型据当前上下文做显式推理，明确下一步要做什么）、Action（若需要，模型返回 tool\_calls 指定工具与参数）、Observation（执行工具，把结果以 role=tool 回喂 messages）；如此循环直到得到最终答案。第二，终止条件：①模型不再发 tool\_calls，直接返回最终答案，这是正常终止；②达到 max\_iter 或 token / 时间预算，这是兜底终止；③检测到重复或振荡，即同一工具、同一参数被反复调用，应中止或改走人工或降级路径；④超时或上游异常，应中断并返回可读错误。第三，常见问题：①工具结果过大撑爆上下文，需截断、摘要或分页；②并行调用管理，多个 tool\_calls 的顺序、依赖与结果合并；③幻觉参数，模型编造不存在的工具或参数，需做 schema 校验并在失败后回喂错误；④循环振荡与死循环，靠 max\_iter、重复检测、超时三重兜底；⑤工具异常，要包成 error 文本回喂，让模型有机会自纠。第四，可举一例：查天气时先 Thought 判断需要天气工具，Action 调用 weather (city)，Observation 返回结果后模型不再调工具，直接输出最终回答。

**要补的关键点**：讲清 Thought/Action/Observation 显式推理三要素；终止条件覆盖正常终止、max\_iter、重复振荡、超时；常见问题展开：结果过大、并行调用、幻觉参数、循环振荡、异常回喂；配一个具体例子串联循环
