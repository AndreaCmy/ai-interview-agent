# 演示录屏脚本（75 秒）

> **已有一版现成的**：`demo/walkthrough.gif`（26 秒，终端实录，asciinema + agg 生成），已内嵌在 README 顶部。
> 想自己重录再用本文的分镜；不想录直接沿用 GIF 即可。

> 用途：GitHub 仓库首页 / 简历里的「演示视频」入口。
> 目标不是讲代码，而是让人 75 秒内相信三件事：**能跑、真的调用模型、成本可控**。

> 如果只想录 P1（题库 + 单题打分，更短更轻），直接用文末的 **P1 版 60 秒脚本**。

## 一、录之前准备（5 分钟）

- 终端窗口调到 **1280×800 左右**，字号放大到 **18px 以上**（录屏在小窗里播，字小等于没录）。
- 先 `clear` 清屏，确认提示符干净（不要出现一长串绝对路径）。
- 关掉系统通知、微信、邮件弹窗。
- **不要打开 `.env`**，也不要 `cat` 任何含 key 的文件。本项目的 LLM 客户端不会打印 key，但自己别手欠。
- 用 `demo/bank-1q.json`（已有的 1 题题库）来录，一场 **2 次调用**，20 秒左右跑完，好拍也好省钱。
  - 想展示 2 题就复制一份改成两题，一场 3 次调用。
- 提前想好答案文本，**直接粘贴**，不要现场打字（打字会拖垮节奏）。

## 二、分镜表

| 时间 | 画面 | 操作 | 要说的话（口播/字幕） |
|---|---|---|---|
| 0–8s | 终端 | `./practice.sh stat` | 「这是我的 AI 面试 Agent。左边是我的 JD 和简历原件，右边是生成的题库和报告。」 |
| 8–12s | 终端 | `./practice.sh help`（快速滚过） | 「入口就一个脚本：init / prep / start / ask / stat。」 |
| 12–45s | 终端 | `python -m app interview --bank demo/bank-1q.json --max-calls 2 -o demo/report-recording.md` | 逐题出现 → 粘贴回答 → **停在 `[LLM 调用 1/2]` 那一行 1 秒** |
| 45–55s | 终端 | 滚动到打分结果 | 「六维分数出来了，总分 3.10 是**代码算的**，不是模型给的。」 |
| 55–65s | 编辑器 / 浏览器 | 打开 `demo/report-recording.md` | 「复盘报告：亮点、待补、改进话术、复习优先级。」 |
| 65–72s | 浏览器 | 打开 https://andreacmy.github.io/ai-interview-agent/ | 「回放页是零外链单文件，点开就能看，不用装环境。」 |
| 72–75s | 定格 | —— | 结束卡：仓库地址 + 「LLM 调用上限 = 题数 + 1」 |

## 三、可选插段：15 秒代码（放在 45–55s 之间，代替报告那一段）

只在**你确实想强调「手写」**时才加，且只拍两处，各 6 秒：

```bash
# 1) ReAct 循环本体（约 30 行）
sed -n '1,40p' app/agent.py

# 2) 硬预算包装（约 20 行）
sed -n '1,40p' app/budget.py
```

口播一句话即可：「循环是我自己写的，工具调用、消息拼装都在这里；外面包了一层预算，超次数直接抛异常。」

**不要**在录屏里逐个文件讲代码——那是 30 分钟的事，没人看。

## 四、拍摄要点

- 全程**一镜到底不加速**，剪辑只做两处：掐掉开头 2 秒、掐掉结尾回车。
- 每个关键输出停留 ≥1 秒，让画面能被截图当封面。
- 录完检查：**画面里有没有出现 key、路径里的用户名、其他项目的窗口**。
- 成片 720p 以上，文件名 `demo-walkthrough.mp4`，放仓库根目录或 Release 附件（不要塞进 git 历史里，视频 10 MB+ 会让 clone 变重）。
  - 推荐：`Release` 里传视频，README 里贴链接。

## 五、README 里怎么挂

```markdown
**演示视频（75 秒）**：[demo-walkthrough.mp4](https://github.com/AndreaCmy/ai-interview-agent/releases/download/v0.1/demo-walkthrough.mp4)
```

## 六、常见翻车点

| 现象 | 原因 | 处理 |
|---|---|---|
| 录出来字太小 | 没放大字号 | 终端 18px+，窗口 1280×800 |
| 提示符带超长路径 | 没 `clear`、没简化 PS1 | 录前 `export PS1='$ '` |
| 答题环节卡住 | 现场打字 | 提前把答案存成文本，用粘贴 |
| 报告没生成 | 中途 Ctrl+C | 重跑前先 `ls demo/report-*.md` 确认 |
| 泄露个人材料 | 开了 `my/` 下的文件 | 只开 `demo/report-1q.md` 这类中性样例 |

# P1 版脚本（60 秒）

> 只讲「读 JD + 简历 → 生成题库 → 单题打分」，不涉及整场面试。
> 成本：**2 次 LLM 调用**（prep 1 次 + ask 1 次），比整场版更轻。

## 分镜

| 时间 | 操作 | 画面里会出现什么 |
|---|---|---|
| 0–5s | `./practice.sh stat` | 素材清单：JD、简历、题库、报告 |
| 5–8s | `./practice.sh help` | 一条命令说清 5 个子命令 |
| 8–28s | `./practice.sh prep 10` | 1 次调用 → 屏幕滚出 **10 道针对本人简历出的题**（停在第 3 题） |
| 28–45s | `./practice.sh ask "请讲讲 ReAct 循环的步骤、终止条件与常见坑。" "每轮把 messages 发给模型；模型若返回 tool_calls 就执行工具、以 role=tool 回喂；直到模型不再调工具返回最终答案。用 max_iter 兜底，工具异常包成 error 文本回喂，避免死循环。"` | 1 次调用 → **六维分数 + 加权总分 + 亮点/待补** |
| 45–52s | 打开 `demo/report-1q.md` | 逐题改进话术、复习优先级 |
| 52–60s | 浏览器打开 https://andreacmy.github.io/ai-interview-agent/ | 回放页，收尾定格 |

## P1 版的三处注意

- `prep` 会**覆盖** `my/bank.md`（重生成 10 题，1 次调用）。录之前先备份：`cp my/bank.md my/bank.md.bak`。
- `ask` **不写数据库**，只打印分数，所以录完不会有脏数据。
- 题库题目会带出简历里的项目名（如「Grab 外卖订单交易履约系统」），这是**加分项**（证明是个性化出题）；但要确认画面里不出现姓名、手机号、邮箱——`prep` 只打印题目，不打印简历原文，所以安全。
- 想更彻底脱敏：把 `my/raw/` 里的原件换成一个虚构岗位的 JD + 虚构简历，跑出的题库就是脱敏样例。
